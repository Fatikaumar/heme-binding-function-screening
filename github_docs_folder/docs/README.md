# Research documentation

Project: **Evaluating Protein Language Models for Function-Based Screening of Heme-Binding Proteins Against Traditional Sequence-Search Methods**

This folder describes the completed Phase 1 pilot. Files are organised as follows:

1. [`01_research_overview.md`](01_research_overview.md) — research question, scope, and protein groups.
2. [`02_methodology.md`](02_methodology.md) — BLASTp and ESM-2 workflows and evaluation metrics.
3. [`03_phase1_results.md`](03_phase1_results.md) — numerical findings from completed runs.
4. [`04_limitations_and_next_phase.md`](04_limitations_and_next_phase.md) — limitations and proposed focused extension.

The underlying data are in `../data/`, notebooks in `../notebooks/`, result exports in `../results/`, and figures in `../figures/`.

**Status:** Phase 1 analyses have been run in Google Colab. The consolidated GitHub notebooks are organised for reproducibility but have not yet been independently rerun end-to-end as a set.
